# NEON RONIN

ネオン都市を舞台にした、ブラウザで遊べる2D剣戟アクションゲームです。外部ライブラリや画像素材を使わず、HTML CanvasとJavaScriptだけで動作します。

## 遊び方

- 移動: `WASD` または矢印キー
- 攻撃: `J` またはスペース
- ダッシュ: `K` またはShift
- スマートフォン: 画面上のタッチボタン

敵を連続で倒すとコンボ倍率が上がります。大型の敵は3回攻撃すると倒せます。

## ローカルで起動

`index.html`をブラウザで開くだけで遊べます。ローカルサーバーを使う場合は、任意の静的ファイルサーバーでこのフォルダを公開してください。
